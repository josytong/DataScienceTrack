# API Mini-Project

## Overview

This mini-project demonstrates how to collect, clean, analyze, and visualize weather data using the Open-Meteo API.

## Objectives

- Retrieve weather data using an API.
- Convert JSON API responses into pandas DataFrames.
- Clean and prepare time-series data.
- Resample hourly data into daily and weekly summaries.
- Visualize and compare weather patterns between locations.

## Analysis

The project includes:

- New York City and Los Angeles weather analysis for January 2023.
- A comparison of temperature, humidity, and precipitation.
- London and Seattle weekly rainfall comparison for 2022.

## Tools

- Python
- Jupyter Notebook
- pandas
- Matplotlib
- Requests
- Open-Meteo API
