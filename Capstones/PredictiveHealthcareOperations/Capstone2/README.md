# Capstone Two: Predictive Healthcare Operations & Capacity Analytics

## Overview

This project analyzes California hospital financial and utilization data from the California Department of Health Care Access and Information (HCAI).

The goal is to identify patterns in hospital operations, utilization, capacity, staffing, and financial measures to support predictive healthcare operations analysis.

## Data

* **Source:** HCAI California Hospital Quarterly Financial & Utilization Reports
* **Period:** 2021 Q1 – 2026 Q1
* **Records:** 9,179 hospital-quarter records
* **Variables:** 159 after combining the quarterly files

## Project Workflow

1. Data acquisition and understanding
2. Data wrangling
3. Exploratory data analysis
4. Preprocessing and training
5. Predictive modeling
6. Evaluation and interpretation
